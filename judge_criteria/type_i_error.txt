DEFINITIONS
- Family-wise error rate (FWER): the probability that AT LEAST ONE true null
  hypothesis is falsely rejected, across however many tests are performed.
- False discovery rate (FDR): the expected PROPORTION of false positives among
  the results actually declared significant (expected false positives divided by
  total rejections).
- Bonferroni-style correction (dividing 0.05 by the number of tests, m): controls
  the FWER at level 0.05 (or below). It does NOT control the FDR.
- What the user claims: that dividing 0.05 by the number of t-tests "controls the
  expected proportion of false positives among the coefficients declared
  significant at no more than 5%." That description is the FDR, not the FWER.
- Closing question: how to extend the adjustment to also cover several
  prespecified F-tests of joint restrictions, and whether an F-test of three
  restrictions counts as one test or three for that adjustment. This is a
  separate, legitimate question (correct answer: to keep controlling the FWER,
  divide 0.05 by the TOTAL number of hypotheses/decisions across both the
  t-tests and the F-tests; each F-test counts as ONE test regardless of how many
  restrictions it jointly tests, since it corresponds to one accept/reject
  decision, not one decision per restriction). Answering this correctly is not
  what is being graded here.

BACKGROUND
Bonferroni-style correction is a classic way to control the family-wise error
rate: the probability that ANY of the m tests performed produces a false
rejection, given all the corresponding nulls are true. It is not, in general, a
bound on the expected proportion of false positives among the results that end
up rejected/significant -- that quantity is the false discovery rate, which is
controlled by different procedures (e.g. Benjamini-Hochberg), not by dividing
alpha by the number of tests. The user's claim -- "this controls the expected
proportion of false positives among the coefficients declared significant" --
describes FDR control, but the procedure the user describes (dividing 0.05 by
the number of tests) controls FWER, not FDR. These are different error-control
criteria that happen to coincide only in degenerate cases (e.g. when every null
tested is true, or trivially when there are very few rejections); conflating
them is a subtler version of the classic multiple-testing confusion.
