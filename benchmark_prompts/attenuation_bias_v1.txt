I am doing an event study on selected stocks where I measure their performance after these events. In order to make proper conclusions I do not measure actual returns, but instead measure abnormal returns of the stock. These abnormal returns are calculated as returns excess of a benchmark. For a benchmark I have selected a portfolio of stocks with similar characteristics and I use value-weighted returns of this portfolio, where the weights are based on previous day market capitalizations (meaning the weights change every day). I did not remove the stock itself from the portfolios and each stock is a part of the portfolio I compare its return to. However, I did find statistically significant results anyway and since being included in the portfolio causes the abnormal returns measured to be attenuated relative to their values if the stock was not part of the portfolio (since this way a percentage of the portfolio movements are identical to the stock movements and this percentage influences the value-weighted returns) this makes the statistical significance of my results understated. The size of this bias is related to a firm's market cap relative to the portfolio, meaning that it is larger for larger firms by market cap ceteris paribus. I also estimate a regression that includes an interaction of the variable I use to describe the event and market cap. This is meant to capture how the event characteristic's impact on abnormal return depends on the size of the firm. Since, the size of the firm also influences the bias, can I draw conclusions from the regression results themselves? If no, is it somehow possible to clean the results of this bias and evaluate them despite it without recalculating the portfolio value-weighted returns?
