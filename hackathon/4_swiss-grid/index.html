Method Each model answers the same 4 planted-premise prompts, 5 runs each. Three judges are drawn at random from a cheap-model panel, seeded per answer, provider-disjoint from the model under test. A verdict requires a panel majority; ties are left ungraded.
Reading the numbers Cost is Vercel AI Gateway list price (marketCost), not discounted API billing. Output tokens include reasoning/thinking tokens where the provider bills for them.
