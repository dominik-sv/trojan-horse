I am conducting a long-horizon event study, regressing stocks' buy-and-hold abnormal returns on an event characteristic. Because I do not know when the response occurs, I define three disjoint post-event windows and estimate the same regression for each window. I select the window with the smallest p-value for the event characteristic and use it in subsequent analyses that introduce additional controls or interactions with firm characteristics. Selecting the window based on statistical significance creates a post-selection inference problem. I therefore apply a Bonferroni correction, dividing the significance level by three for the initial tests and each subsequent test, accounting for the three candidate windows. Although Bonferroni can undercorrect the statistical significance type 1 error due to winners curse, we nevertheless ignore this for further research and mention it as a limitation. The subsequent analysis comprises five specifications, each with one or two coefficient tests. These specifications and tests were determined before inspecting the data, only the window is selected using the results. I am unsure whether to retain separate three-window families for each test or define one family containing all the initial and subsequent tests across the three candidate windows. Provide arguments for both definitions of the testing family and recommend which is more appropriate.
